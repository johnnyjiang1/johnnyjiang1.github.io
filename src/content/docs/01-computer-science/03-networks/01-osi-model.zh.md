---
title: OSI 七层模型
description: OSI 七层参考模型、各层名称及主要职责。
---

OSI（Open Systems Interconnection，开放系统互连）模型是描述网络通信功能的七层参考模型，从上到下如下：

| 层级 | 中文名称 | 英文名称 | 作用 |
| --- | --- | --- | --- |
| 第 7 层 | 应用层 | Application Layer | 为应用程序提供网络服务，常见协议包括 HTTP、FTP、Telnet、SMTP、POP3 和 NFS。 |
| 第 6 层 | 表示层 | Presentation Layer | 处理数据表示与格式转换，例如字符编码、压缩及加密/解密。 |
| 第 5 层 | 会话层 | Session Layer | 建立、管理和终止会话，提供对话控制与同步功能。 |
| 第 4 层 | 传输层 | Transport Layer | 提供端到端的数据传输，功能可包括分段与重组、连接管理、流量控制和差错恢复。 |
| 第 3 层 | 网络层 | Network Layer | 进行逻辑寻址、路由选择和数据包转发。 |
| 第 2 层 | 数据链路层 | Data Link Layer | 将比特组织成帧，进行链路上的数据传输、物理寻址和差错检测。 |
| 第 1 层 | 物理层 | Physical Layer | 定义传输原始比特的介质、信号和接口特性，例如电信号、光信号或无线电信号的编码与传输。 |
