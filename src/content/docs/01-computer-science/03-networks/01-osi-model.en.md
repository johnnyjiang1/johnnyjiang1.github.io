---
title: OSI Seven-Layer Model
description: The OSI reference model, its seven layers, and their main responsibilities.
---

The Open Systems Interconnection (OSI) model is a seven-layer reference model describing network communication functions. Its layers, from top to bottom, are:

| Layer | Name | Responsibilities |
| --- | --- | --- |
| 7 | Application Layer | Provides network services to applications; common protocols include HTTP, FTP, Telnet, SMTP, POP3, and NFS. |
| 6 | Presentation Layer | Handles data representation and format conversion, such as character encoding, compression, and encryption/decryption. |
| 5 | Session Layer | Establishes, manages, and terminates sessions, providing dialogue control and synchronization. |
| 4 | Transport Layer | Provides end-to-end data transfer, with functions that may include segmentation and reassembly, connection management, flow control, and error recovery. |
| 3 | Network Layer | Performs logical addressing, routing, and packet forwarding. |
| 2 | Data Link Layer | Organizes bits into frames and handles data transfer over a link, physical addressing, and error detection. |
| 1 | Physical Layer | Defines the media, signals, and interface characteristics for transmitting raw bits, such as the encoding and transmission of electrical, optical, or radio signals. |
