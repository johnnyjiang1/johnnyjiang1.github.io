# 什么是回归

回归的目的是用来预测数值（可以是连续数值，也可以是人数等离散数值）。与之相对的，分类用于预测样本所属的类别。

举例而言，预测明天的天气状况是晴天，雨天还是多云可以被认为是分类，而预测明天的温度可以被认为是回归。

通过特定操作，我们可以将部分分类问题转换为回归问题，比如用回归算法拟合一个函数后，通过设定阈值的方式来进行分类。举例而言，假设预测降水概率可以是一个回归算法（仅作为举例，实际上一般是别的概率算法），我们可以通过先预测降水概率，然后通过设定阈值来决定是否认为明天会是雨天。

# 一元线性回归

## 适用场景
一元线性回归是机器学习中用法最简单、含义最容易理解的算法之一。如果数据有一个一维的自变量x和一个一维的因变量y，且数据在平面坐标系中大致沿一条直线分布时，我们可以使用线性回归的方式去拟合这些数据点。

## 拟合步骤
对于大部分机器学习算法，我们需要使用一种函数来评估拟合的好坏。这种函数我们称之为损失函数。一般而言，损失函数的结果是非负的，而拟合的步骤就是将损失函数尽可能地减小。

比如，有数据点$(x_1, y_1), (x_2, y_2), \ldots, (x_n, y_n)$满足近似线性分布，那么对于线性回归，我们可以假设拟合过程中某个一元线性函数是：$y = kx + b$。我们可以定义一个损失函数：

$Loss = \sum_{i=1}^{n}(y_i - \hat{y}_i)^2 = \sum_{i=1}^{n}(y_i - (kx_i + b))^2$

其中$(x_i, y_i)$都是实际的数据点，而$\hat{y}_i$是通过将$x_i$代入一次函数求出来的预测值。

这个损失函数叫做残差平方和（SSE, Sum of Squared Errors），是回归算法中最常用的一种损失函数。残差的意思是真值和预测值的差，而平方是为了消除负号，避免正负残差相互抵消，同时也对更大的误差给予更大的惩罚。在定义了这个损失函数之后，在数据点确定的情况下，这个函数是一个关于$k$和$b$的二元二次函数：

$Loss = \sum_{i=1}^{n}(y_i - (kx_i + b))^2 = \sum_{i=1}^{n}(y_i)^2 + \sum_{i=1}^{n}(x_i)^2k^2 + nb^2 - 2\sum_{i=1}^{n}(x_iy_i)k - 2\sum_{i=1}^{n}(y_i)b + 2\sum_{i=1}^{n}(x_i)kb$

由于这个损失函数是关于参数的仿射函数（总次数至多为1的多项式函数）的平方之和，如果画一个三维的函数曲面，则这是一个开口朝上的凸曲面，有一个最低点（注：当所有数据的$x$相同时，这个凸曲面会退化为开口向上的抛物柱面，此时最小值的点组成一条直线，因此最低点不唯一 - 不过这个实际应用场景这种情况基本不会发生）。显然，导数为0时可以取到这个点。通过分别对$k$和$b$偏微分，我们可以得到以下式子：

$\frac{\partial Loss}{\partial k} = 2\sum_{i=1}^{n}x_i(kx_i + b - y_i) = 0$

$\frac{\partial Loss}{\partial b} = 2\sum_{i=1}^{n}(kx_i + b - y_i) = 0$

两个式子分别代入数据后，我们得到了一个二元一次的方程组。解这个方程就可以得到损失函数取最小值时的$y = kx + b$。

# 多元线性回归

当每个样本有$d$个输入特征时，第$i$个样本可表示为$(\mathbf{x}_i, y_i)$。其中，$\mathbf{x}_i=(x_{i1}, x_{i2}, \ldots, x_{id})$是输入向量，$x_{ij}$表示第$i$个样本的第$j$个特征，$y_i$是观测值。该样本的预测值为：

$\hat{y}_i = \alpha_0 + \alpha_1x_{i1} + \alpha_2x_{i2} + \ldots + \alpha_dx_{id}$

我们可以利用类似一元线性回归的方法，定义损失函数，对每一项的系数做偏微分后，得出由这些系数组成的多元一次方程组，然后解出方程即可。
